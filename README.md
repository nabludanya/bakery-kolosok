# 🥐 Булочная «Колосок»

Сайт булочной с каталогом товаров, формой добавления нового товара и контактной информацией.
Выполнен в рамках **лабораторной работы №3** по теме «Применение каскадных таблиц стилей при создании web-сайта».

## 🌐 Демо

Открыть сайт: **[https://nabludanya.github.io/bakery-kolosok/](https://nabludanya.github.io/bakery-kolosok/)**

## 📄 Страницы сайта

| Страница | Файл | Назначение |
|---|---|---|
| 🏠 Главная | `index.html` | Приветствие, преимущества булочной, кнопка перехода в каталог |
| 🛒 Товары | `products.html` | Каталог из 6 товаров с фотографиями, описанием и ценой |
| ➕ Добавить товар | `add.html` | Форма добавления нового товара с валидацией полей |
| 📞 Контакты | `contacts.html` | Адрес, телефон, email и часы работы |

## 🎨 Использованные технологии

- **HTML5** — семантическая разметка (`<header>`, `<nav>`, `<main>`, `<section>`, `<table>`, `<form>`, `<footer>`)
- **CSS3** — два отдельных файла стилей:
  - `styles/main.css` — уникальный дизайн **только** для главной страницы
  - `styles/others.css` — общий стиль для трёх внутренних страниц

## 📚 Что реализовано по заданию

### Псевдоклассы
- `a:link`, `a:visited` — цвета непосещённых и посещённых ссылок
- `a:hover` — подсветка пунктов меню и кнопок при наведении
- `input:focus`, `select:focus`, `textarea:focus` — золотая подсветка активного поля формы
- `tr:hover` — подсветка строки таблицы при наведении
- `.product-img:hover` — плавное увеличение фотографии товара

### Селекторы `id`
- `#top-header` — шапка главной страницы
- `#main-footer` — подвал главной страницы
- `#map` — блок карты на странице контактов
- `#product-name`, `#product-category`, `#product-price`, `#product-desc`, `#product-photo` — поля формы добавления

### Селекторы `class`
- `.main-nav` — навигационное меню на главной
- `.logo`, `.slogan` — логотип и слоган
- `.welcome`, `.btn`, `.features`, `.feature-list`, `.badge` — блоки главной страницы
- `.container`, `.products`, `.price`, `.product-img` — элементы каталога
- `.add-form`, `.contact-info` — форма и блок контактов
- `.active` — выделение текущей страницы в меню
